# БД6 · Бронирование столов

Учебное CLI-приложение на Python и PostgreSQL. В меню можно добавлять,
просматривать, изменять и удалять пользователей, столы и бронирования,
а также проверять доступность стола на выбранное время.

## Запуск в PowerShell

1. Подготовьте Python 3.10+ и PostgreSQL с расширением `btree_gist`.
2. В pgAdmin создайте отдельную базу `bd6_booking`. Подойдёт
   сервер из БД5. Потребуются права на создание таблиц в схеме `public`
   и установку расширения `btree_gist` в новой базе.
3. Из папки проекта выполните:

   ```powershell
   python -m venv .venv
   .\.venv\Scripts\python.exe -m pip install -r requirements.txt
   if (-not (Test-Path .env)) { Copy-Item .env.example .env }
   notepad .env
   ```

4. Укажите в `.env` хост, порт, имя базы, пользователя PostgreSQL и пароль.
   Затем запустите заполнение учебными данными и откройте меню:

   ```powershell
   .\.venv\Scripts\python.exe app.py --seed
   .\.venv\Scripts\python.exe app.py
   ```

При запуске приложение автоматически создаёт `public.users`, `public.tables`
и `public.bookings`. В пустой базе `--seed` добавляет трёх пользователей,
три стола и два бронирования. При повторном запуске записи не дублируются.

## Проверка

- Список бронирований открывается через **3 Бронирования → 1 Список**.
- В свежей учебной базе выберите **4 Проверить доступность**, введите ID стола
  `1` и интервал `2026-12-01 18:30`–`2026-12-01 18:45`. CLI сообщит,
  что стол занят. Интервал с `19:00` до `20:00` для этого стола свободен.
  Если база уже использовалась, уточните ID через **2 Столы → 1 Список**.
- В pgAdmin обновите список **Databases → bd6_booking → Schemas → public →
  Tables**. Через **View/Edit Data → All Rows** можно просмотреть записи
  каждой таблицы. Для общей проверки счётчиков выполните в Query Tool:

  ```sql
  SELECT (SELECT count(*) FROM public.users) AS users,
         (SELECT count(*) FROM public.tables) AS tables,
         (SELECT count(*) FROM public.bookings) AS bookings;
  ```

Интервалы задаются в местном времени ресторана. Конец одной брони может
совпадать с началом другой. PostgreSQL защищает от пересечений на одном
столе при создании и изменении брони, включая одновременные операции.
Перед удалением пользователя или стола нужно удалить связанные бронирования.

## Файлы проекта

- `models/` содержит модели `User`, `Table` и `Booking` со схемами таблиц.
- `postgres_driver.py` загружает настройки из `.env`, управляет транзакциями и создаёт схему.
- `backend.py` реализует CRUD, проверку доступности и заполнение учебными данными.
- `app.py` содержит меню и команды запуска.
